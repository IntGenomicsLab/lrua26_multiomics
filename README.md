# LRUA26_multiomics

Hello! This repository contains short and simple [tutorial](fiberseq_chr20_tutorial.md) to start with for Fiber-seq data processing. It is supplementary material to Multiomics workshop given at LRUA 2026. 

We use publicly available data, downsample it and demonstrate how to run a few simple fibertools commands and how to interpret their output.
